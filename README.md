# Ольга Бушмина — аналитик данных

Анализирую продажи, ассортимент и поведение покупателей. Использую SQL, Python и Excel для подготовки данных, расчёта метрик, проверки гипотез и визуализации результатов.

Работала с данными собственного интернет-магазина: анализировала продажи и ассортимент, контролировала товарные остатки, планировала закупки и оценивала эффективность рекламы. Использовала данные МойСклад, Webasyst и Яндекс.Метрики.

## Избранные проекты

### [Прогноз продаж и моделирование закупок в Excel](https://github.com/Olyshon/sales-forecast-inventory-model)

<a href="https://github.com/Olyshon/sales-forecast-inventory-model">

</a>

Сценарная модель на реальных данных собственного интернет-магазина. Сравнение методов прогнозирования спроса и моделирование пополнения запасов с учётом срока поставки и условий заказа.

**Результат:** в одном из модельных сценариев увеличение страхового запаса снизило дефицит с 220 до 36 единиц при увеличении среднего остатка с 13,8 до 33,3 единицы.

**Инструменты:** Excel, прогнозирование спроса, WAPE, сценарное моделирование.
